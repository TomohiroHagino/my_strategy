# ハンズオン：エージェント（tool use / 関数呼び出し）

> 対応する理屈 → [../エージェント.md](../エージェント.md)。前提 → [setup.md](./setup.md)。

## ゴール
Claude に「使える関数」を渡し、**Claude がいつ・どの引数で呼ぶかを判断 → こちらが実行 → 結果を返して続きを答えさせる**ループ（tool use）を手で書く。LLM 単体が苦手な**計算**をツールにやらせる。

---

## ステップ1：ツールを定義する
**やること**：名前・説明・入力スキーマを書く。
```python
# agent.py
import anthropic
client = anthropic.Anthropic()

TOOLS = [{
    "name": "calculate",
    "description": "数式を計算して結果を返す。算数・四則演算が必要なとき使う。",
    "input_schema": {
        "type": "object",
        "properties": {"expr": {"type": "string", "description": "例: (12000*1.1)/3"}},
        "required": ["expr"],
    },
}]
```
**なぜ**：`description` が「いつ使うか」をモデルに教える最重要部分。曖昧だと誤呼び出しする。
**成功**：定義できればOK。

## ステップ2：実行する関数（普通のPython）
**やること**：ツールの中身を書く。**引数は必ず検証**。
```python
import ast, operator as op
OPS = {ast.Add: op.add, ast.Sub: op.sub, ast.Mult: op.mul,
       ast.Div: op.truediv, ast.USub: op.neg, ast.Pow: op.pow}
def safe_eval(node):
    if isinstance(node, ast.Constant): return node.value
    if isinstance(node, ast.BinOp):   return OPS[type(node.op)](safe_eval(node.left), safe_eval(node.right))
    if isinstance(node, ast.UnaryOp): return OPS[type(node.op)](safe_eval(node.operand))
    raise ValueError("許可されていない式")
def calculate(expr: str):
    return safe_eval(ast.parse(expr, mode="eval").body)   # eval() は使わない（危険）
```
**なぜ**：**LLMが出した文字列を `eval()` で実行するのは重大な脆弱性**。許可した演算だけ通す＝入力検証。
**成功**：`calculate("(12000*1.1)/3")` が `4400.0`。
**失敗の原因**：`eval` を使いたくなる → 禁止。任意コード実行になる。

## ステップ3：tool use ループを回す
**やること**：Claudeが「呼びたい」と言ったら実行し、結果を返して続けさせる。
```python
def run(question, max_steps=5):
    msgs = [{"role": "user", "content": question}]
    for _ in range(max_steps):                         # ★ ループ上限（暴走防止）
        r = client.messages.create(model="claude-haiku-4-5", max_tokens=500,
            tools=TOOLS, messages=msgs)
        if r.stop_reason != "tool_use":                # ツール要求が無ければ完了
            return "".join(b.text for b in r.content if b.type == "text")
        msgs.append({"role": "assistant", "content": r.content})  # 応答(tool_use含む)を積む
        results = []
        for b in r.content:
            if b.type == "tool_use":
                print(f"  → Claudeが {b.name}({b.input}) を要求")
                out = calculate(**b.input)             # ここで実際に実行
                results.append({"type": "tool_result",
                                "tool_use_id": b.id, "content": str(out)})
        msgs.append({"role": "user", "content": results})         # 結果を返す
    return "（上限に達した）"

print(run("時給1200円で7.5時間×22日働くといくら？最後に金額だけ円で。"))
```
**なぜ**：**Claudeは「呼びたい」と言うだけ、実行するのは常にこちらのコード**。だから安全制御を握れる。`stop_reason=="tool_use"` が続く限りループ。
**成功**：途中に `→ Claudeが calculate(...)` が出て、正しい金額で答える。
**失敗の原因**：
- 無限ループ/高額 → `max_steps` 必須。
- `tool_use_id` の不一致エラー → 各 tool_use に1対1で tool_result を返す（idを合わせる）。
- assistant応答を積み忘れ → 履歴が壊れる。`msgs.append({"role":"assistant",...})` を必ず。

## ステップ4：ツールを足す（複数ツールから選ばせる）
**やること**：現在時刻ツールを足し、Claudeに使い分けさせる。
```python
import datetime
TOOLS.append({
    "name": "now", "description": "現在の日時(JST)を返す。今日や今の時刻が必要なとき使う。",
    "input_schema": {"type": "object", "properties": {}},
})
def now():
    return datetime.datetime.now().strftime("%Y-%m-%d %H:%M")

# run() の実行部を分岐に：
#   if b.name == "calculate": out = calculate(**b.input)
#   elif b.name == "now":     out = now()
```
**なぜ**：複数ツールから**descriptionを読んで適切な方を選ぶ**のがエージェントの肝。
**成功**：「今日は何日？」で `now`、「○○円は？」で `calculate` が呼ばれる。
**失敗の原因**：間違ったツールを呼ぶ/呼ばない → descriptionを磨く（最大の改善点）。

## ステップ5：危険操作には承認を挟む（安全設計）
**やること**：副作用のあるツールは実行前に人の確認を入れる発想を体験。
```python
def dangerous_delete(target):
    ans = input(f"[確認] '{target}' を本当に削除？ yes/no > ")   # human-in-the-loop
    if ans.strip().lower() != "yes":
        return "ユーザーが拒否したため中止"
    return f"{target} を削除した（ふり）"
```
**なぜ**：エージェントは**外の世界を変えられる＝事故ると実害**。不可逆・高影響な操作は**承認・許可リスト・ループ上限**で守る（このリポジトリ全体の「不可逆操作は確認してから」と同じ）。
**成功**：no と打つと中止される。
**失敗の原因**：LLMの判断だけで削除を自動実行 → 事故る。必ず人を挟む。

## わざと壊して直す
1. ステップ3の `max_steps` を消し、ツールを呼び続けるような曖昧な指示を出す → 止まらない/課金が増える。**上限を必ず付ける**。
2. `calculate` を `eval(expr)` に置き換え、`expr="__import__('os')..."` を試す（※安全な環境で）→ 任意コード実行の怖さを理解し、`safe_eval` に戻す。
