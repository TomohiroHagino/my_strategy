# Gin

## 一言で
Go で最も定番の**軽量・高速なWebフレームワーク**。radix tree ベースの高速ルーター＋**ミドルウェアの連鎖**が核。標準 `net/http` より便利な薄い層を足したもので、API構築に向く。Echo / Fiber と並ぶ人気。

## 特徴
- **高速ルーティング**（radix tree）。
- **ミドルウェア中心**：`r.Use(...)` で繋いだ関数を順に通る。
- **`gin.Context`（`c`）** にリクエスト/レスポンス操作が集約。
- **バインド＆バリデーション**：構造体タグで JSON を検証込みで受ける。
- 薄く無規約：構造・ORM・認証は自分で選んで足す。

## どういう使い方をするのか
- **REST API / マイクロサービス / BFF**。
- 軽量Webアプリ・Webhook。

## 強み / 弱み
- 強み：速い・軽い・実績多い・学習しやすい。
- 弱み：無規約ゆえ大規模で構造がばらつく（自前で秩序を作る）。フルスタックではない。
