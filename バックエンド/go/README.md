# Go

## 一言で
Google が作った**静的型付けのコンパイル言語**。シンプル・高速・**並行処理（goroutine）が得意**で、**静的バイナリ1個**にコンパイルされるためデプロイが極めて楽。クラウド/インフラ/API/CLI の定番（Docker・Kubernetes・Terraform 自体が Go 製）。

## 特徴
- **意図的にシンプル**：機能を絞り、誰が書いても似たコードになる（`gofmt` で整形統一）。
- **goroutine ＋ channel**：軽量スレッドで並行処理を素直に書ける。
- **明示的なエラー処理**：例外でなく `err` を戻り値で返す（`if err != nil`）。
- **構造的インターフェース**：「そのメソッドを持てば実装」（暗黙的に満たす）。
- **静的バイナリ**：依存ごと1ファイルにコンパイル。コンテナが小さい。
- 高速コンパイル・GC・標準ライブラリが厚い。

## どういう使い方をするのか
- **API / マイクロサービス**（高並行・低レイテンシ）。
- **CLI ツール・インフラツール**（Docker/k8s 等）。
- 高スループットなサーバ・ミドルウェア。

## 強み / 弱み
- 強み：速い・並行に強い・**デプロイが簡単（1バイナリ）**・学習しやすい・標準ライブラリが強い。
- 弱み：**エラー処理が冗長**（`if err != nil` 連発）・表現力は抑えめ（意図的）・ジェネリクスは後発（1.18+）。

## エコシステム・周辺
- モジュール: `go mod`、整形/静的解析: `gofmt` / `golangci-lint`
- テスト: 標準 `testing`（テーブル駆動）
- Web: 標準 `net/http` ／ **Gin**（→ [gin/](./gin/)）/ Echo / Fiber / chi
- ORM: GORM / sqlx
