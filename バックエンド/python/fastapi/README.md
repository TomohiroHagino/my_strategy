# FastAPI

## 一言で
**型ヒント駆動の、モダンで高速な API フレームワーク**。Pydantic による自動バリデーション、`async` ネイティブ、そして**コードからSwagger(OpenAPI)ドキュメントが自動生成**されるのが最大の特徴。API構築の新定番。

## 特徴
- **型ヒントが仕様になる**（検証・変換・ドキュメントが自動生成）。
- **Pydantic モデル**でリクエスト/レスポンスの形を宣言。
- **async ネイティブ**（ASGI / Uvicorn）。
- **依存性注入（`Depends`）** と **自動ドキュメント（`/docs`・`/redoc`）**。

## 強み / 弱み
- 強み：開発速度・型安全・自動ドキュメント・高性能。
- 弱み：フルスタックではない（admin/テンプレート等は別途）。非同期の誤用に注意。
