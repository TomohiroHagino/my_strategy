# Python

## 一言で
「読みやすさ」を最優先に設計された汎用の動的言語。Web・データ分析・AI/ML・自動化まで横断して使われ、特にデータ／AI領域では事実上の標準。

## 特徴
- **インデントで構文を表す**（波括弧なし）。誰が書いても似た見た目になり可読性が高い。
- **動的型＋漸進的型付け**: 型宣言は任意だが、`typing` の型ヒント＋mypyで安全性を足せる。
- **電池付属（batteries included）**: 標準ライブラリが厚い。
- **マルチパラダイム**: 手続き・OOP・関数型を混ぜて書ける。
- **CPythonのGIL**: 1プロセスで同時にPythonバイトコードを実行するのは1スレッド（CPU並列は別プロセス/ネイティブ拡張で）。

## どういう使い方をするのか
- **Webアプリ／API**: Django（フルスタック）/ FastAPI（API・非同期）/ Flask（軽量）。
- **データ分析・科学計算**: pandas / NumPy / Polars。
- **AI / 機械学習**: PyTorch / TensorFlow / scikit-learn（→この分野の主役）。
- **自動化・スクリプト・CLI**。

## 強み
- 学習しやすく情報が豊富。可読性が高くチーム開発向き。
- データ／AIのエコシステムが圧倒的。
- 書くのが速い（プロトタイピングに強い）。

## 弱み・注意点
- 実行速度は遅め（重い処理はC拡張やNumPy、別言語に逃がす）。
- GILでCPU並列が苦手（multiprocessing / ネイティブで回避）。
- 動的型ゆえ大規模では型ヒント＋mypyが実質必須。
- モバイル／フロントには不向き。

## 向いている場面 / 向かない場面
- 向いている: Web/API、データ・AI、自動化、プロトタイピング。
- 向かない: CPUバウンドな低レイテンシ処理、モバイル、組み込み。

## エコシステム・周辺ツール
- パッケージ/環境: pip / venv / Poetry / **uv**（高速）
- 品質: ruff（lint/format）/ black / mypy（型）
- テスト: pytest / unittest
- Web: **Django**（→ [django/](./django/)）/ FastAPI / Flask
- 実行: Gunicorn / Uvicorn（ASGI）＋ nginx
