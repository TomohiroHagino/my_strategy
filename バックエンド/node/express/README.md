# Express

## 一言で
Node.js で**最も定番の、薄くて自由なWebフレームワーク**。「**ミドルウェアの連鎖**」が設計の核。規約や全部入り機能は持たず（ORM・認証・構造は自分で選ぶ）、最小限の土台だけ提供する。

## 特徴
- **ミドルウェア中心**：リクエストが `app.use(...)` で繋いだ関数の列を順に通る。これがExpressの全て。
- **薄い・無規約（unopinionated）**：ディレクトリ構造もORMも自由。だから小さく始められるが、大きくすると自前で秩序を作る必要。
- **巨大なミドルウェア資産**：認証・CORS・ログ・セキュリティ等は既製ミドルウェアを足す。
- **Express 5**（現行）：Node 18+、**async関数の例外を自動でエラーハンドラへ転送**、ルート記法(path-to-regexp)刷新 など。

## どういう使い方をするのか
- **REST API / BFF**（フロントは別：React等）。
- 軽量な Web アプリ・Webhook・マイクロサービス。
- 学習・プロトタイプの最初の一歩。

## 強み / 弱み
- 強み：軽い・自由・情報と実績が豊富・学習が速い。
- 弱み：無規約ゆえ大規模で構造がばらつく（→ 構造化したいなら **NestJS**、速度重視なら **Fastify** も候補）。
