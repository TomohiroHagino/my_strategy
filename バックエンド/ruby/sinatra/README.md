# Sinatra

## 一言で
Ruby の **最小限の“マイクロ”Webフレームワーク**。「URL ↔ 処理」を数行で書けるのが身上。Rails のような全部入り（ORM・admin・generator）は持たず、必要な物だけ自分で足す。小さなAPI・1ファイルアプリ・プロトタイプに最適。

## 特徴
- **超軽量・薄い**（Rack の上の薄い層）。
- **ORM等は内蔵しない**（DBは ActiveRecord / Sequel を足す）。
- **2スタイル**：1ファイルの classic と、クラスにする modular。

## 強み / 弱み
- 強み：学習が速い・起動が軽い・構成が透明。
- 弱み：大きくなると自前で構造を作る負担が増える（→ Rails を検討）。
