# ベストプラクティス

## ひとことで言うと
**Claude Code を使いこなすための、全機能を貫く原則の総まとめ**。突き詰めると3つ——**①良い文脈を与える ②検証で裏取りする ③自動化の許可は最小から**。個々の機能（コマンド・サブエージェント・フック）はこの原則を実現する手段にすぎない。

## なぜ必要か / どこで効くか
- 機能を覚えても、**原則を外すと精度も安全も出ない**（文脈不足で誤る／検証なしで嘘を信じる／許可しすぎて事故）。
- 逆にこの3原則を守れば、機能の選択は自然に決まる。**「何を使うか」より「なぜそれを使うか」**が効く。

## 原則① 良い文脈を与える
LLMの出力品質は**与えた文脈の質でほぼ決まる**。
- **常時の前提は CLAUDE.md**（規約・構成・使うコマンド）。毎回口で説明しない。
- **都度の対象は `@file` で明示**。「あのファイル」ではなく具体的に指す。
- **1セッション＝1タスク**に近づけ、無関係作業を混ぜない（混ぜると文脈汚染）。
- **広く読む調査はサブエージェント**に逃がし、メインには結論だけ返す。
- **長くなったら整理**：タスクが変わったら `/clear`、同一タスクが長引いたら `/compact`。

> 文脈は"足せばよい"ではない。**コンテキストウィンドウは有限**で、無関係な文脈は肝心の指示を薄める。**要点を厳選**する。

## 原則② 検証で裏取りする
出力は**確率的でブレ、それらしく間違える**。だから「できました」を信じない。
- **テストを正解の定義に**：TDD で先にテストを固め、機械的に真偽を判定。
- **バグ修正はまず再現テスト**を書かせてから直す。
- **変更直後にレビュー**（code-reviewer / security-reviewer / 言語別）。
- **必ず走らせたい検証はフックで強制**（整形・Lint・型・テスト）。お願いに頼らない。
- **最終防壁は CI**：フックをすり抜けても止める多層防御。

## 原則③ 自動化の許可は最小から
**自動化を増やすほど、暴走時の被害も増える**。
- 権限は**最小から始めて広げる**：安全な読み取り・テストは allow、外向き/破壊系は ask か deny。
- **`--dangerously-skip-permissions` は常用しない**。
- **コミット・push・デプロイは人の承認**。勝手に外向き操作をさせない。
- **MCP は信頼できるサーバだけ**。書き込み系ツールは承認制。
- フック/コマンドに**任意コード実行**を仕込むときは出所を確認（供給網リスク）。

## 機能の選択早見（原則→手段）
| 課題 | 原則 | 手段 |
|---|---|---|
| 毎回同じ説明が無駄 | ①文脈 | CLAUDE.md |
| 定型作業がブレる | ①文脈 | スラッシュコマンド / Skill |
| 調査でメインが溢れる | ①文脈 | サブエージェント |
| 「できた」が信用できない | ②検証 | TDD・レビュー |
| 毎回必ずやらせたい | ②検証 | フック |
| 事故が怖い | ③許可 | permissions（ask/deny） |
| 外部接続が必要 | ③許可 | MCP（信頼＋承認） |

## 効く頼み方（プロンプトのコツ）
- **具体的に**：「直して」より「`X` が `Y` で落ちる。再現テストを書いてから直して」。
- **手順を指定**：探索→計画→実装→検証の順を明示すると暴走しにくい。
- **大きいタスクは分割**：小さく刻むと検証・軌道修正・レビューが楽。
- **難所だけ深く考えさせる**（拡張思考）。単純作業では使わない。
- 軌道がずれたら **Esc で止めて修正**。plan mode なら**承認前に差し戻す**のが最も安い。

## コスト/速度の勘所
- **モデルを使い分ける**：機械的作業は高速・低コスト、難所だけ上位モデル。
- **プロンプトキャッシュ**で共通プレフィックスを使い回す（→ [../生成AI/運用とコスト.md](../生成AI/運用とコスト.md)）。
- **文脈を絞る**こと自体がコスト削減（無駄なファイルを読ませない）。
- バッチ/CI は**ヘッドレス(`-p`) → 必要なら API/SDK**（[08_api_sdk連携.md](./08_api_sdk連携.md)）。

## アンチパターン総覧
- **巨大タスクを丸投げ** → 分割＋ plan mode。
- **検証手段を渡さない** → テスト/ビルドを回させる。
- **1セッションに何でも詰める** → `/clear` で分ける。
- **危険操作を無制限許可** → 最小権限＋承認。
- **自動化をメモリ/プロンプトで頼む** → フック（settings）に落とす。
- **CLAUDE.md 肥大** → 要点だけ、分割。
- **出力を無検証でコミット/副作用** → レビュー・スキーマ検証。
- **モデルID・料金を記憶で決め打ち** → 最新を確認。
