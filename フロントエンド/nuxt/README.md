# Nuxt

## 一言で
**Vue の上に乗るフルスタックフレームワーク**（Next.js の Vue 版）。ファイルベースルーティング・SSR/SSG・データ取得・サーバAPI（Nitro）を内蔵し、Vue だけでは足りない部分を埋める。

## 特徴
- **ファイルベースルーティング**（`pages/`）と**自動インポート**（components / composables）。
- **ユニバーサルレンダリング**（SSR）／SSG／SPA を選べる。
- **Nitro サーバ**：`server/api/` でAPIを同居（フルスタック）。
- **`useFetch` / `useAsyncData`** でSSR対応のデータ取得。
- モジュールエコシステムが豊富。

## Vue との関係
```
 Vue   … UIを部品＋リアクティビティで組む（クライアント）
 Nuxt  … その上に ルーティング/SSR/データ取得/サーバAPI を足した「フレームワーク」
```
→ まず [../vue/](../vue/) の基礎、その上にこれ。
