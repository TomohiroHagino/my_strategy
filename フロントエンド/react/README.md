# React

## 一言で
UIを**部品（コンポーネント）**に分け、**状態(state)から画面を組み立てる**ライブラリ。`UI = f(state)`（画面は状態の関数）で、手でDOMをいじらず「状態を変える→Reactが再描画」する。フレームワークではないので、ルーティングやデータ取得は別ライブラリを足す。

## 特徴
- **コンポーネント指向**：関数コンポーネント＋JSX。
- **宣言的UI**：状態から画面を宣言、差分はReactが反映（仮想DOM）。
- **フック**：`useState`/`useEffect` 等でロジックを組む。
- **エコシステムで補う**：ルーティング(React Router)・データ取得(TanStack Query)・状態管理(Redux/Zustand)を選んで足す。

## 強み / 弱み
- 強み：巨大エコシステム・求人最多級・部品の再利用・TSと好相性。
- 弱み：ライブラリゆえ「素」では足りない（構成を自分で組む）。SSR等が要るなら Next.js。
