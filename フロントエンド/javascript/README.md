# JavaScript（フロントエンド）

## 一言で
ブラウザで動く唯一の言語として始まった、動的型付けのスクリプト言語。今は**フロント・バック（Node）・ツールまで横断**する。Webの「動き」を担う土台で、React/Vue 等もすべてこの上に乗る。

## 特徴
- **動的型付け・プロトタイプベース**。関数が第一級（高階関数・クロージャ）。
- **イベント駆動・非同期**：`Promise` / `async`・`await` でI/Oを待たずに進める。
- **DOM操作**：HTML要素をJSから取得・変更・イベント登録する（フロントの基本）。
- **モジュール**：`import`/`export`（ESM）。ブラウザもNodeも対応。
- **ES（ECMAScript）で毎年進化**：分割代入・スプレッド・オプショナルチェイン等。

## どういう使い方をするのか
- **ブラウザのUI制御**（DOM・イベント・fetch通信）。
- **React / Vue 等のフレームワーク**の土台。
- ビルドツール・CLI・サーバ（Node）。

## 強み / 弱み
- 強み：どこでも動く・学習の入口が広い・エコシステム最大級。
- 弱み：**型が無い**ため大規模で壊れやすい（→ TypeScript で補う）。歴史的な落とし穴（`==`、`this`、暗黙変換）。

## まず押さえる中核概念（フロント文脈）
- DOMとイベント（`querySelector` / `addEventListener`）
- 非同期（`Promise` / `async`・`await` / `fetch`）
- 配列メソッド（`map` / `filter` / `reduce`）
- スコープとクロージャ、`this`
- モジュール（ESM）、分割代入・スプレッド

## エコシステム・周辺
- 実行: ブラウザ / Node.js、パッケージ: npm
- 型付け: **TypeScript**（→ [../typescript/](../typescript/)）
- UIフレームワーク: React / Vue（→ [../react/](../react/) / [../vue/](../vue/)）
- ビルド: Vite / esbuild
