# ハンズオン：Vue 3 アプリを0から作って、カウンタと一覧とAPI表示まで動かす

> **このファイルの位置づけ**：他のファイル（[getting_started.md](./getting_started.md) / [reactivity.md](./reactivity.md) 等）は「分かっている人が引く辞書」。
> これは**手を動かして1回成功するための実習**。上から順にコピペすれば、0から画面が出るところまで行けます。

## ゴール（終わったら何ができる？）
- Vite で Vue 3 アプリを作って、**ブラウザに自分の画面が出る**
- `ref` を使った**カウンタ**を作れる
- `v-for` で**配列を一覧表示**できる
- `fetch` で**公開API**のデータを取って並べられる
- わざと **`ref` の `.value` 取り違え**を起こして、自分で直せる
- ここまでやると [getting_started.md](./getting_started.md) / [reactivity.md](./reactivity.md) / [directives.md](./directives.md) が「読める」ようになる

**所要時間**：20〜30分　**前提**：Node 20+ が入っていること（それ以外の知識は不要）

---

## 準備：Node が使えるか確認
**やること**：Node のバージョンを見る。
**なぜ**：Vite も Vue も Node の上で動く。古すぎると途中で失敗する。
```bash
node -v
```
**成功**：`v20.x.x`（または v22 など）と出る。
**失敗**：
- `command not found` → Node 未インストール。[nodejs.org](https://nodejs.org/) の LTS を入れて再実行。
- `v18` 以下 → LTS（20+）に上げると安全。

ホームに移動:
```bash
cd ~
```

## ステップ1：Vite で Vue プロジェクトを作る
**やること**：Vite の `vue-ts` テンプレートで雛形を生成する。
**なぜ**：Vue を実務で書くにはビルド環境＋SFC（`.vue`）＋TypeScript が要る。Vite がその足場を一発で用意してくれる。
```bash
npm create vite@latest my-vue-app -- --template vue-ts
```
- `my-vue-app`＝作るフォルダ名、`-- --template vue-ts`＝「TypeScript版のVueテンプレートで」という指定。
- **`--` を省くと**テンプレ指定が Vite に渡らず対話モードになる。npm 経由では `-- --template vue-ts` と書く。

> 公式ツール `npm create vue@latest`（create-vue）もあるが、こちらは Router/Pinia/Vitest などを対話で選ぶ重め構成。ここでは最小で動かすため Vite テンプレートを使う。→ [getting_started.md](./getting_started.md)

**成功**：`Scaffolding project in .../my-vue-app...` → `Done.` で終わる。
**失敗**：
- 途中で質問が出て止まる → `--` を付け忘れ。`Ctrl+C` で中止し、上のコマンドを貼り直す。

---

## ステップ2：依存をインストールして開発サーバを起動する
**やること**：パッケージを入れて `npm run dev`。
**なぜ**：雛形だけでは動かない。Vue 本体などの部品を入れ、開発サーバを立てて初めて画面が出る。
```bash
cd my-vue-app
npm install
npm run dev
```
**成功**：ターミナルに次が出る。
```
  VITE v6.x.x  ready in xxx ms

  ➜  Local:   http://localhost:5173/
```
ブラウザで **http://localhost:5173** を開く。
**画面に見えるもの**：Vite と Vue のロゴ、`Vite + Vue` の見出し、`count is 0` のボタン。**ボタンを押すと数字が増える**（雛形のサンプル）。

**失敗**：
- `Port 5173 is in use` → 表示された別ポートを開く。
- 真っ白＋赤エラー → `npm install` が失敗していないか確認し、再実行。

> このあと保存するたびに**ブラウザが自動更新**される（HMR）。`npm run dev` は起動したままにしておく。

## ステップ3：画面を自分の中身に置き換える（refでカウンタ）
**やること**：`src/App.vue` を、自分で書いた最小のカウンタに丸ごと置き換える。
**なぜ**：Vue の核は「**状態(ref)を変えると、それを使うテンプレートが自動で再描画される**」。`ref` がその入り口。→ [reactivity.md](./reactivity.md)

エディタで `my-vue-app/src/App.vue` を開き、中身を**すべて消して**次に置き換える:
```vue
<script setup lang="ts">
import { ref } from 'vue'

// ref = リアクティブな状態の箱。<script> 内では .value で読み書きする
const count = ref(0)
const increment = () => {
  count.value++
}
</script>

<template>
  <main style="padding: 24px; font-family: sans-serif;">
    <h1>これは自分のVueページ</h1>
    <!-- テンプレート内では .value 不要（自動アンラップ） -->
    <button @click="increment">押した回数: {{ count }}</button>
  </main>
</template>
```
保存する。
**画面に見えるもの**：ロゴが消え、**「これは自分のVueページ」という見出し**と、`押した回数: 0` のボタン。**クリックするたびに数字が増える**。

**読み解き**：
- `<script>` の中では `count.value++`（**`.value` が要る**）。
- `<template>` の中では `{{ count }}`（**`.value` は不要**＝自動アンラップ）。
- この「場所による `.value` の有無」がVueの最初の関門。→ [reactivity.md](./reactivity.md)

**失敗**：
- ボタンを押しても増えない → `<script>` 内で `count++`（`.value` 無し）にしていないか。`count.value++` が正しい。
- 画面が真っ白 → `<template>` を消していないか。`<script setup>` と `<template>` の両方が必要。

## ステップ4：v-for で配列を一覧表示する
**やること**：固定の配列を `v-for` でリスト表示する。
**なぜ**：`v-for` は「配列をHTML要素に展開する」Vueの基本ディレクティブ。後のAPI表示の土台になる。→ [directives.md](./directives.md)

`src/App.vue` を次に置き換える:
```vue
<script setup lang="ts">
import { ref } from 'vue'

const count = ref(0)
const increment = () => {
  count.value++
}

// 固定の配列（あとでAPIに置き換える）
const fruits = ref(['りんご', 'みかん', 'ぶどう'])
</script>

<template>
  <main style="padding: 24px; font-family: sans-serif;">
    <h1>これは自分のVueページ</h1>
    <button @click="increment">押した回数: {{ count }}</button>

    <h2>くだもの一覧</h2>
    <ul>
      <!-- v-for で配列を <li> に展開。:key で各要素を区別する -->
      <li v-for="fruit in fruits" :key="fruit">{{ fruit }}</li>
    </ul>
  </main>
</template>
```
保存する。
**画面に見えるもの**：カウンタの下に「くだもの一覧」が出て、**`りんご` `みかん` `ぶどう` の3行**が並ぶ。

**読み解き**：`v-for="fruit in fruits"` で配列の各要素について `<li>` を1つずつ作る。`:key`（＝ `v-bind:key` の短縮形）は「どの行がどれか」をVueに教える目印。→ [directives.md](./directives.md)

**失敗**：
- 何も表示されない → `v-for` のスペルや `:key` の付け忘れを確認。
- `fruit is not defined` のような警告 → `v-for="fruit in fruits"` の変数名と `{{ fruit }}` が一致しているか確認。

## ステップ5：fetch で公開APIのデータを表示する
**やること**：公開API（ユーザー一覧）からデータを取って、`v-for` で並べる。
**なぜ**：実務のVueは「APIから取って画面に並べる」が大半。その最小形を体験する。

`src/App.vue` を次に置き換える:
```vue
<script setup lang="ts">
import { ref, onMounted } from 'vue'

type User = { id: number; name: string }

const count = ref(0)
const increment = () => {
  count.value++
}

// 最初は空配列。API取得後に詰める
const users = ref<User[]>([])

// 画面が表示されたあと（マウント後）に1回だけ実行
onMounted(async () => {
  const res = await fetch('https://jsonplaceholder.typicode.com/users')
  users.value = await res.json()
})
</script>

<template>
  <main style="padding: 24px; font-family: sans-serif;">
    <h1>これは自分のVueページ</h1>
    <button @click="increment">押した回数: {{ count }}</button>

    <h2>ユーザー一覧（APIから取得）</h2>
    <ul>
      <li v-for="user in users" :key="user.id">{{ user.name }}</li>
    </ul>
  </main>
</template>
```
保存する。
**画面に見えるもの**：「ユーザー一覧（APIから取得）」の下に、**`Leanne Graham` などの名前が10件ほど**並ぶ。一瞬遅れて表示されるのは、APIからの取得を待っているため。

**読み解き**：
- `onMounted(...)` は「画面が表示されたあとに1回だけ実行」する場所。ここでAPIを取る。→ [lifecycle.md](./lifecycle.md)
- 取得後に `users.value = ...` と**`.value` 経由で代入**すると、テンプレートの `v-for` が自動で再描画される。

**失敗**：
- リストが空のまま → ネットワーク遮断やAPI一時障害。F12 → Network タブで失敗していないか確認。
- リストが更新されない → `users = await res.json()`（`.value` 無し）にしていないか。`users.value = ...` が正しい。

## ステップ6：わざと `ref` の `.value` 取り違えを起こして直す
**なぜ**：`.value` の付け忘れ／付けすぎは Vue で最頻出のミス。自分で起こして直すと一生忘れない。

`src/App.vue` の `increment` を**わざと壊す**（`.value` を外す）:
```vue
const increment = () => {
  count++   // ← .value を外した（間違い）
}
```
保存する。
**結果**：エディタ（TypeScript）が赤線を出し、ターミナルにも型エラーが出る。
```
The left-hand side of an arithmetic operation must be of type 'number'...
（count は Ref<number> なので、そのまま ++ できない）
```
ブラウザのボタンを押しても**数字が増えない**（または型エラーで動かない）。
**読み解き**：`count` は `ref(0)` が返す「**Refオブジェクト（値の箱）**」であって、数値そのものではない。中身の数値を触るには `<script>` 内では **`.value`** を通す必要がある。テンプレート内だけは自動でアンラップされるので `.value` が不要、という非対称が混乱の元。→ [reactivity.md](./reactivity.md)

直す（`.value` を戻す）:
```vue
const increment = () => {
  count.value++   // ← 正しい
}
```
保存する。
**成功**：型エラーが消え、**ボタンを押すと数字が増える**。→ 「`<script>` 内は `.value`、`<template>` 内は不要」を体験で理解できた。

> 関連の取り違えに `reactive`（オブジェクト用）と `ref`（あらゆる値用）の混同もある。**プリミティブ値は `ref`、複数フィールドのオブジェクトは `reactive`**、迷ったら `ref` が無難。→ [reactivity.md](./reactivity.md)
