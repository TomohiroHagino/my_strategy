# 言語共通概念（言語横断）

> 特定の言語に属さず、**言語をまたいで比較すると理解が深まる概念**を置く場所。
> 各言語の `解説/` ファイルからここへリンクし、ここからも各言語へ戻れるようにする。

## なぜ分けるか
「値渡しか参照か」「型システム」「並行モデル」などは、1言語の中だけで読むより**複数言語を横に並べて違いで捉える**方が腹落ちする。各言語ファイルに同じ比較表を重複させないための共通置き場。

## 項目
- [値渡しと参照.md](./値渡しと参照.md) … 関数に渡した変数の中身を変えると呼び出し元に伝わるか。全11言語（Java/Python/Ruby/PHP/Go/JS/TS/Rust/Dart/Kotlin/Swift）をメモリ図＋比較表で。
- [言語間の移行ギャップ.md](./言語間の移行ギャップ.md) … ある言語の癖が別の言語で事故になるパターン集（値/参照・nil vs ゼロ値・文字列の可変性・エラー処理・真偽値・等価性・並行モデル）。例：Go脳でRubyを書くと引数を破壊する。
- [型システム.md](./型システム.md) … 静的/動的・公称/構造的・null安全・型推論・ジェネリクスを11言語比較表で。「強い型≠静的型」の整理、公称vs構造的の対比。
- [並行非同期モデル.md](./並行非同期モデル.md) … スレッド/GIL/goroutine+channel/async-await/actor/isolate/所有権を11言語比較表で。「並行 vs 並列」「競合をどう防ぐか（ロック/メッセージパッシング/所有権）」。
- [エラー処理.md](./エラー処理.md) … 例外 / 戻り値のerr / Result・Option の機構を11言語比較表で。Goの`if err`・Rustの`?`・例外の書き味対比。使い分けの設計判断は [../設計/エラー設計.md](../設計/エラー設計.md)。
- [等価性.md](./等価性.md) … 同値（中身が等しい）と同一（同じ物）の区別。`==`/`===`/`equals`/`eql?`/`is` の意味を11言語比較表で。JSの型変換・Javaの文字列`==`罠など事故源も。

## 今後足せる候補
- 文字列・文字コード（可変/不変・エンコーディング・コードポイント vs バイト）
- 真偽値と「偽っぽい値」（falsy の範囲が言語で違う）
- メモリ管理（GC / 参照カウント / 所有権・借用）
- 数値（整数のオーバーフロー・浮動小数・任意精度の有無）
